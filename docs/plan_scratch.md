# 我的想法
1. 统一对cli的输入、输出、特殊命令（如/model）、session进行管理。
2. 对于session要有本地的储存，既有特定cli的元数据如session id直接恢复，也要有挑选有价值的session直接存储对话历史
3. 后期考虑给主agent全局记忆功能
