## Frontend - Single Source of Truth

The ONLY source file for the frontend is **`ts/app.ts`** (TypeScript).

- **`static/js/app.js`** is a **compiled artifact** generated by `npx tsc`. It is gitignored.
- NEVER edit `static/js/app.js` directly. Always edit `ts/app.ts` instead.
- After editing `ts/app.ts`, run `npx tsc` to compile the JS output.
- Pre-commit hook via `git config core.hooksPath scripts` verifies TS compilation.

## Port Configuration

Service port is configured in `config.json` (gitignored). Each branch has its own:
- `main` branch → port `8767`
- `test` branch → port `8768`

`main.py` reads from `load_config().get("port")`. Environment variable `CLICONDUCTOR_PORT` overrides.
